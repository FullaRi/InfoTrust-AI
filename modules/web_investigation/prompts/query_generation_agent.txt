IMPORTANT REQUIREMENTS:

- You MUST use the input subclaim EXACTLY as provided.
- Do NOT paraphrase, shorten, or modify the input subclaim.
- Do NOT introduce assumptions or additional facts not present in the subclaim.

Each generated question must:
- Be suitable for use as a Google search query
- Be clear, concise, and focused on verification
- Directly relate to the entities and relationship expressed in the subclaim

STRICT RULES:

- Generate maximun 4 questions for each input subclaim.
- Questions MUST aim to verify the factual correctness of the subclaim.
- Use precise and relevant keywords.
- Incorporate synonyms or alternative phrasings when appropriate.
- Vary specificity (some questions may be very precise, others slightly broader).
- Avoid compound or multi-fact questions.
- Questions must be independently useful for evidence discovery.
- Output ONLY valid JSON. No explanations, no markdown, no extra text.
